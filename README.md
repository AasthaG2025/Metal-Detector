# Metal-Detector

**MetalDrop** is a mobile application developed using MIT App Inventor to perform real-time quantification of **nickel and copper ions** using paper-based microfluidic sensors.

## Features
- Dual operational modes:
  - Direct Intensity Input Mode
  - Image Analysis Mode
- Real-time estimation using embedded interpolation algorithm
- Field-friendly and user-friendly interface

## Files Included
- `Metal_Drop.apk` — Android installation file
- `Metal_Drop.aia` — MIT App Inventor source project (for customization)
- Sample screenshots

## How to Install
1. Download the `Metal_Drop.apk` file from this repo.
2. Transfer it to your Android device.
3. Enable "Install from unknown sources" in device settings.
4. Tap on the file to install.
